# 🚦 E-Challan Revenue & Case Analysis using SQL

## 🔍 Overview

This project analyzes e-challan (traffic violation) data to uncover trends in challan issuance, revenue collection, and case resolution efficiency. The goal is to provide actionable insights that can support better traffic enforcement and policy decisions.

## 🛠 Tools Used

* SQL (MySQL)

## 📁 Dataset

* Records: 4000+ rows
* Fields: Date, Challan Counts, Revenue Amounts, Court Cases

## 📊 Key Business Questions

* What is the total revenue generated from challans?
* How do challan counts and revenue trend over time?
* What is the disposal efficiency of challans?
* How significant is the backlog of pending cases?
* How effective is revenue collection from issued challans?

## 💻 SQL Analysis

The project uses SQL queries involving:

* Aggregations (`SUM`, `COUNT`)
* Date functions (`YEAR`, `MONTH`, `DATE_FORMAT`)
* Sorting & ranking (`ORDER BY`, `LIMIT`)
* Derived metrics (rates & percentages)
## 📈 Key Insights

* 💰 Significant revenue is generated through challans, with noticeable peaks in certain periods.
* 📈 Challan issuance shows an increasing trend, indicating stricter traffic enforcement.
* ⚠️ A considerable portion of challans remain pending, highlighting inefficiencies in resolution.
* ⚖️ Court-related cases contribute to backlog, suggesting scope for process improvement.
* 📊 Revenue collection efficiency indicates that not all issued challans are successfully converted into payments.

## 💡 Conclusion

The analysis highlights operational inefficiencies in challan resolution and revenue collection. Addressing pending cases and improving enforcement follow-ups can significantly enhance system effectiveness.
